# LoupeDeck CT for DaVinci Resolve — Function & Options Catalog

Source: `z.srt`, the 21:57 walkthrough transcript, with the video frame-checked against each CT page. Timestamp references point to the source video. This catalog records actions/options named or demonstrated in the transcript; it does not claim to reproduce hidden actions from the Gumroad profile file. The screenshot-backed [Master Reference](Loupedeck-CT-Master-Reference/LoupeDeck-CT-Master-Reference.html) records 168 separate mapped actions and selectable options, including separate dial turns/presses, timer durations, colors, export presets, and Fn combinations.

## Device and navigation

- 8 round buttons select pages: 1 Media, 2 Edit 1, 3 Edit 2, 4 Edit 3, 5 Color, 6 Fairlight, 7 Deliver, 8 Quick Export. The Resolve page can stay the same while the CT touchscreen changes pages. (00:00:34–01:05)
- 12 touchscreen buttons change with the selected page. Six dials each support turn and press. The CT also uses the center wheel, square buttons, and Fn. (01:08–01:24)
- Round buttons 2–4 are three tool pages for Resolve's Edit page. Play/Pause is available on all Edit pages. (00:00:44–00:00:54; 05:31–05:40)

## Page 1 — Media / Project Manager

### Project and media

- **Project Settings:** set project frame size and frame rate. Example shown: 1080p, 25 fps. (01:35–01:50)
- **New Bin:** create media-pool folders/bins. Example: Music and Footage. (01:50–02:02)
- **Import Media:** open the file picker and import selected audio/video into the selected bin. (02:02–02:21)
- **Power Bins:** toggle Power Bins visibility; Power Bins are reusable between projects (e.g., logos and titles). (02:21–02:33)
- **Project Notes / Note:** open, write, save, and close project notes. (02:33–02:44)
- **Project Manager:** open to open or switch projects, then close to return. (02:44–02:51)
- **New Project:** open the create-project flow; cancel is available. (02:51–02:57)
- **Prefer Proxy:** make Resolve use available proxy media for playback. (02:57–03:10)
- **Camera Originals:** switch back to the original camera files. (03:10–03:15)

### Timeline-format utilities

- **Studio edition:** Timeline 9×16, Timeline 4×5, Timeline 4×3 create alternate-format copies of the finished timeline; original remains unchanged. Intended examples: TikTok/Reels/Shorts (9×16), Instagram feed (4×5), and 4×3. (03:15–03:29; 21:00–21:24)
- **Free edition alternative:** Duplicate Timeline and New Timeline appear in this row instead. (03:29–03:36)

### Break Timer (Studio only)

- Swipe the touchscreen right from the Media page to open it. (03:36–03:45)
- Choose a work interval; the demonstrated choice is **25 minutes**, then press **Start**. A status button indicates that the timer is running. (03:45–03:56)
- **Stop** ends the timer early. When the interval elapses, it gives a reminder without stopping the edit. (03:59; 15:08–15:29)
- **Rushwise** button opens Rushwise, described by the narrator as a project manager for DaVinci editors. (04:01–04:06)
- The video frame confirms all eight interval choices: **25 minutes, 45 minutes, 1 hour, 1.5 hours, 2 hours, 2.5 hours, 3 hours, and 4 hours**. The remaining buttons are Rushwise, Break! status, Start, and Stop.

## Page 2 — Edit 1

### Timeline creation, zoom, transport, navigation

- **New Timeline** (on Edit 3): create a named timeline; example name “City Film.” (04:18–04:37)
- **Zoom to Fit:** press the middle-right dial to fit the full timeline onscreen. (04:44–04:52)
- **Center wheel:** move the playhead frame by frame; turn right forward, left backward. Press the wheel center for Play/Pause. (04:59–05:07; 05:40–05:44)
- **Top-left dial — Shuttle:** frame-by-frame playhead movement. (05:09–05:13)
- **Top-right dial — Fast Shuttle:** each dial step moves one second. (05:13–05:18)
- **Bottom-right dial — Next Clip:** jump cut-to-cut. (05:18–05:22)
- **Middle-right dial — Zoom:** zoom timeline in/out. (05:22–05:25)
- **Square D:** jump to timeline end; **square C:** jump to timeline start. (05:25–05:31)
- **Play/Pause touchscreen button:** start/pause playback; tap again to stop. Present on all three Edit pages. (05:31–05:40)
- **Add Marker:** press the bottom-right dial. With a clip selected, add a clip marker; with nothing selected, add a timeline/ruler marker. (05:44–06:07)

### Editing actions

- **Ripple Start:** remove the selected clip's portion before the playhead and close the resulting gap. (06:07–06:21)
- **Ripple End:** remove the selected clip's portion after the playhead and close the gap. (06:21–06:32)
- **Split Clip:** cut a clip at the playhead. (06:32–06:41)
- **Delete:** delete selected clip; leaves a gap. (06:41–06:51)
- **Trim Start / Trim End:** shorten the clip while leaving the other timeline material in place; gaps remain. (06:51–07:06)
- **Select Forward All:** select everything to the right of the playhead. (07:06–07:16)
- **Select Backward All:** select everything to the left of the playhead. (07:16–07:20)
- **Snapping:** toggle magnetic snapping to clip edges; off permits free placement (including one-frame offsets). (07:20–07:42)
- **Change Clip Speed:** set speed as a percentage; example 200%, which doubles speed and halves duration. (07:42–07:57)
- **Retime Controls:** toggle the speed controls/indicator on the clip. (07:57–08:03)

### Clip colors and audio level

- Press the color dials to assign clip colors: **top-left Orange**, **middle-left Yellow**, **top-right Green**. (08:03–08:19)
- Turn the **middle-left dial** with music selected to change audio level; each click changes it by 1 dB. (08:19–08:28)
- **Bottom-left dial — Dynamic Trim:** press to enable/disable; select a cut and turn the dial to move the edit point frame-by-frame while viewing both sides of the cut. (08:28–08:43)

## Page 3 — Edit 2

### Markers, linking, clip organization

- **Delete All Markers:** remove timeline/clip markers. (08:49–09:00)
- **Link:** toggle linked selection. Off selects only the clicked picture or audio item; on selects linked picture and sound together. (09:00–09:15)
- **Link Clips:** unlink linked items, or link separately selected clips so they select/move together. This is distinct from the Link selection toggle. (09:15–09:50)
- **New Compound Clip:** turn selected clips into one compound clip; can be undone. (09:51–10:06)
- **Normalize Audio:** choose a target level and normalize the selected audio. (10:06–10:16)
- **Auto Align:** line up clips by their audio; useful for recordings of the same moment from multiple cameras. (10:16–10:28)
- **Mark In / Mark Out:** set the in/out points of a range. (10:28–10:34)
- **Loop:** toggle repeated playback of the marked range. (10:34–10:42)
- **Match Frame:** open the original source file at the exact current frame. (10:42–10:52)
- **Cinema Viewer:** show the film full screen; Escape exits. (10:52–10:59)
- **Find Clip:** show selected clip in Media Pool. **Find Timeline:** show the timeline in the project/media area. (12:36–12:46)
- **New Timeline:** create a timeline. (12:46–12:50)
- **Duplicate Timeline:** make a working copy so experiments do not risk the original edit. (13:04–13:17)

### Additional clip colors

- Swipe down on the dials to access more colors: **Apricot, Blue, Lime, Brown, Pink, Purple**. (10:59–11:12)
- Swipe down twice on the dials on this page for **Olive, Teal, Navy, Violet, Tan, Beige**. The narrator says there are 15 colors total. (12:50–13:04)

## Page 4 — Edit 3

- **Delete Gaps:** close all timeline gaps in one action. Resolve only closes gaps empty on every track, so the walkthrough disables/excludes the music track first. (11:20–11:43)
- **Swap Left / Swap Right:** exchange the selected clip with the neighboring clip on the left/right. (11:43–11:52)
- **Enable Clip:** toggle a clip off without deleting it; press again to restore it. (11:52–11:59)
- **Freeze Frame:** freeze the picture at the playhead; press again to restore normal playback. (11:59–12:15)
- **Crossfade:** apply a transition between adjacent audio clips. (12:15–12:27)
- **Title Safe:** toggle the safe-area guide for text visible across screens. (12:27–12:36)

## Physical keys, Fn layer and panels

- **Fn modifier:** hold Fn and press another key to invoke its alternate action. Example **Fn+B = Ripple Delete** (delete and close gap). (13:17–13:50)
- **Undo:** restore the last edit. **Save:** save project; the “Edited” indicator disappears. (13:50–14:00)
- **A / B:** move selected clip up/down a track. (14:00–14:06)
- **E:** right-click at the current mouse location. **C / D:** timeline start/end. (14:06–14:15)
- **Fn + Round 1:** Media Pool panel. **Fn + Round 2:** Effects Library (transitions/titles). **Fn + Round 3:** Inspector. **Fn + Round 4:** Mixer. **Fn + Round 5:** Power Bins. **Fn + Round 6:** Metadata. **Fn + Round 7:** Index (timeline cut list). These toggle panels open/closed. (14:15–14:47)
- **Fn+C:** Copy selected clip. **Fn+A:** Paste Attributes; choose which attributes to apply (example: clip color). (14:47–15:08)

## Page 5 — Color

- **Videoscopes:** toggle scopes for checking color and exposure. (15:36–15:48)
- **Add Serial Node:** add an empty serial node. **Add Node Before:** insert a node before the current node. **Label Node:** name a node. (15:48–16:45)
- Three left dials operate on the current node and are **Studio only**: **top-left Saturation**, **middle-left Gamma** (midtones), **bottom-left Gain** (highlights). Press a dial to reset its value. (15:57–16:35)
- Adjusting the controls automatically names the node **Corrections**; narrator says this name cannot be changed. Resolve's own controls visibly follow live only when the node is a Corrections node. (16:05–16:26)
- **Printer Light Hotkeys:** toggle the right-side dials to red/green/blue printer-light adjustments. Press again to exit. (16:45–17:01)
- **Grab Still:** save the current graded frame to the Gallery. (17:01–17:07)
- Comparison toggles: **Split Original** (grade beside original), **Split Stills** (Gallery still beside clip), **Split Selected** (two selected clips side-by-side), **Split Prev/Next** (previous and next clips). Press again to turn comparison off. (17:07–17:33)
- **Top-right dial press:** reset/exit split comparison back to normal. (17:33–17:38)
- **Light Box:** show all clips side-by-side; toggle off. **Cinema Viewer:** judge grade full-screen. (17:38–17:47)
- **Fn+D:** Bypass All Grades to compare original vs graded image. (17:47–17:55)

## Page 6 — Fairlight

- **Batch Fade Settings:** set fade-in and fade-out durations then apply. Example: 1.5 s in, 2 s out. (18:01–18:19)
- **Apply Batch Fades:** apply the saved fade settings to selected audio without reopening the settings window. (18:19–18:29)
- **Middle-left dial:** track height, while mouse is over the tracks. **Bottom-left dial:** waveform size; press to restore. (18:29–18:39)
- Transport/range controls: **Mark In, Mark Out, Loop, Play/Pause**. (18:39–18:48)
- Right-side navigation dials: **Shuttle, Fast Shuttle, Next Clip**. (18:48–18:57)

## Page 7 — Deliver / Render Queue

The preset buttons described below are **Studio only**; each queues the timeline with its corresponding settings. (18:57–19:10)

- Built-in export presets: **YouTube, Vimeo, TikTok, Instagram 4×5, ProRes 422 HQ** (high-quality master). (19:10–19:23)
- **Custom 1 / Custom 2 / Custom 3:** configure a render preset, choose “Save as New Preset,” give it a short name ending in `#1`, `#2`, or `#3` to map it to the corresponding button. The button displays the chosen name. (19:23–19:54)
- **Add to Queue:** add timeline using current render settings. **Render All:** render every job in the queue. **Render New:** render only the newly added job, skipping old queued jobs. **Stop Render:** stop a long-running render. (19:54–20:13)
- Swipe touchscreen right for: **Thumbnail** (save current frame as picture), **Export Folder** (open export location), **Clear Render Queue** (empty queue). (20:13–20:27)
- **Top-left dial press = Mark In; top-right dial press = Mark Out** to export a range. (20:27–20:35)
- Free edition Deliver page: **Quick Export, Add to Queue, Render All, Mark In, Mark Out, Play**. (20:35–20:43)

## Page 8 — Quick Export

- Choose a format, then press Export to render the film. (20:47–20:59)

## Setup / compatibility notes from the walkthrough

- Pack has a DaVinci Resolve **Studio edition** and a **Free edition**. Narrator says features are shared unless identified as Studio only. (00:17–00:27)
- If a button does nothing, select the pack's keyboard shortcuts in DaVinci's Keyboard Customization. In Studio, set External Scripting to **Local**. (21:32–21:43)
- Installation instructions are in a separate video linked in the product description. (00:27–00:33)

## Function counting note

This is a deduplicated action/option catalog, not a vendor's official “120+” count. The screenshot-backed Master Reference counts **168** distinct physical mappings or selectable options. That higher number includes repeated commands reachable from separate controls, dial-turn and dial-press actions separately, timer durations, color choices, and export presets. The number of unique Resolve behaviours is lower because several mappings intentionally repeat Play/Pause, navigation, Mark In/Out, and similar operations.
